# Apollo Healthcare Analytics

Interactive healthcare analytics project built using **Excel, Power BI, and DAX** to analyze patient records, diagnosis patterns, hospital occupancy, billing, and health insurance data.

---

## Project Overview

This project analyzes healthcare data to identify important operational, financial, and patient-related insights through an interactive **Power BI dashboard**.

The analysis focuses on:

- Hospital bed occupancy
- Diagnosis types
- Billing amounts
- Health insurance amounts
- Doctor feedback
- Patient-level analysis
- Date-based filtering

---

## Business Questions

The project was designed to answer the following business questions:

- What is the distribution of hospital bed occupancy across different bed types?
- Which diagnosis types have the highest number of patients?
- How do billing amounts compare with health insurance amounts across diagnoses?
- What is the overall billing amount generated?
- How does doctor feedback volume vary across doctors?
- How can patient-level and date-based filters be used to analyze healthcare records?

---

## Tools & Technologies

- **Excel** — Dataset preparation and data handling
- **Power BI** — Interactive dashboard and data visualization
- **DAX** — Measures and calculated metrics

---

## Dashboard Analysis

The Power BI dashboard contains the following analysis areas:

1. **Bed Occupancy** — Comparison of occupancy across Private, General, and ICU beds.
2. **Doctor Feedback** — Feedback volume distribution across doctors.
3. **Diagnosis Analysis** — Patient distribution across different diagnosis types.
4. **Billing & Insurance Analysis** — Comparison of billing amounts and health insurance amounts across diagnoses.
5. **Patient & Date Filters** — Interactive filtering using Patient ID, admission date, and discharge date.

---

## Key Insights

- Total billing amount was approximately **₹190.43M**.
- Private beds recorded the highest occupancy among the displayed bed types.
- **Viral Infection** had the highest diagnosis volume in the dashboard.
- Billing amount remained higher than health insurance amount across the displayed diagnosis categories.
- Doctor feedback volume was distributed across multiple doctors.
- The dashboard provides interactive filtering for detailed patient-level analysis.
